┌─ TROUBLESHOOTING ────────────────────────────────────────────────────────────┐
│                                                                              │
│  ❌ "Microphone blocked"                                                    │
│      → Click 🔒 in address bar → Allow → Refresh → Try again               │
│                                                                              │
│  ❌ "No speech detected"                                                    │
│      → Speak clearly, loudly, and close to microphone                      │
│      → Or type your symptoms instead                                       │
│                                                                              │
│  ❌ "Not supported"                                                         │
│      → Use Chrome, Edge, or Safari                                         │
│      → Or type symptoms instead                                            │
│                                                                              │
│  ❌ "Send button not working"                                               │
│      → Check text field has content                                        │
│      → Press Enter or click Send button                                    │
│                                                                              │
│  ❌ "Language not changing"                                                 │
│      → Select language BEFORE clicking microphone                          │
│      → Language updates immediately when selected                          │
│                                                                              │
