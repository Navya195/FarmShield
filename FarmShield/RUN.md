# FarmShield - Quick Start Guide

## 🚀 Run the Application

### Windows
```cmd
python run.py
```

### Linux / Mac
```bash
python3 run.py
```

## 🌐 Access the Website

After running the command above, open your browser and go to:

```
http://127.0.0.1:5000
```

## ❌ Troubleshooting

### Python not found
- Install from https://www.python.org
- Check "Add Python to PATH" during installation

### Missing modules
```cmd
pip install flask flask-cors python-dotenv numpy pillow werkzeug
```

### Port 5000 already in use
```cmd
python run.py
```
And open: http://127.0.0.1:5000 in your browser

### Page not loading
- Make sure Flask app is running (check terminal)
- Try refreshing the browser (Ctrl+F5)
- Try http://localhost:5000 instead
