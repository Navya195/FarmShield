FarmShield – Page Descriptions

FarmShield is an AI-powered agricultural assistance platform designed to help farmers identify crop diseases, monitor crop health, and receive intelligent recommendations. The application provides a modern, dark-themed interface with a green agricultural visual identity.

🔐 Login Page

The Login Page provides a secure and user-friendly entry point to the FarmShield application.

Features
FarmShield branding with an agricultural shield logo.
Email address input field with email icon.
Password input field with password visibility toggle.
Remember Me option for convenient future access.
Forgot Password? option for password recovery.
Prominent Sign In to FarmShield button.
Agricultural background image featuring farmland and natural scenery.
Responsive centered login card with a dark glass-style interface.
Decorative agricultural elements such as leaves and glowing particles to reinforce the farming theme.
Light/dark mode toggle available in the interface.
Purpose

The login page authenticates users before providing access to FarmShield's AI-based crop monitoring and disease diagnosis features.

🏠 Home Page

The Home Page acts as the primary landing page and provides quick access to FarmShield's major AI-powered farming features.

Hero Section

The hero section introduces FarmShield with the tagline:

Smart AI Protection for Modern Farming

It communicates the platform's purpose of using AI to support farmers with crop protection and intelligent recommendations.

Main Features

The home page provides three primary actions:

📷 One-Tap Camera – Quickly capture a crop image for analysis.
⬆️ Upload Image – Upload an existing crop image for AI-based diagnosis.
🎙️ Voice Diagnosis – Describe crop problems using voice input.
AI Diagnosis Preview

A sample disease-analysis card demonstrates how FarmShield presents results. The interface displays:

Crop image
Detected disease
Disease category/severity indicator
Symptoms
AI-generated observations

For example, the interface demonstrates detection of Tomato Early Blight and presents relevant symptoms such as discoloration, yellowing, and leaf damage.

Statistics

The home page also highlights platform statistics, such as:

Number of scans performed
AI accuracy
Number of crops analyzed
Number of supported conditions
Purpose

The Home Page gives farmers a simple starting point where they can immediately scan, upload, or describe a crop problem without navigating through complicated menus.

📊 AI Dashboard

The AI Dashboard provides an overview of crop analysis data and farming insights collected through FarmShield.

Dashboard Navigation

The dashboard contains a sidebar with sections such as:

Dashboard
One-Tap Scan
Voice Diagnosis
Community
Reports
Settings
Profile/account-related options
Overview Statistics

The dashboard displays key agricultural metrics through summary cards, including:

Total scans
AI accuracy
Crops analyzed
Diseases detected

These metrics allow users to quickly understand their overall crop-monitoring activity.

Disease Distribution

The Disease Distribution panel presents detected crop diseases and their occurrence counts. This helps users identify which crop problems are appearing most frequently in their analyzed data.

Crop Health Score

The Crop Health Score section provides health indicators for different crops.

The dashboard visually compares crop health using horizontal progress bars, allowing farmers to quickly identify crops that may require additional attention.

Purpose

The AI Dashboard transforms individual crop scans into a broader overview of farm health and disease trends. It provides farmers with a centralized location for monitoring their AI analysis history and understanding crop conditions.

Design Theme

FarmShield uses a dark agricultural UI combined with vibrant green accents to communicate technology, sustainability, and farming. Rounded cards, glowing green highlights, agricultural imagery, charts, and icon-based navigation create a modern AI-focused experience while keeping the interface accessible to farmers.
